# 和弦蠑螈 🎸

給 Cindy 練電吉他和弦的小遊戲。插上吉他，蠑螈會聽你彈的每一下，判斷和弦對不對。

## 線上版

**https://wenfenghsu.github.io/chord-axolotl/**

用 Chrome 或 Edge 打開就能玩，手機、平板、別台電腦都可以。第一次會問麥克風／音源權限，要按允許。

## 在自己電腦上離線玩

雙擊 **`啟動遊戲.command`**，瀏覽器會自動打開。練完把跳出來的黑色視窗關掉就結束。

> 第一次雙擊如果被 macOS 擋下來：在檔案上按右鍵 →「打開」→ 再按一次「打開」。

用 Chrome 或 Edge 開最穩。第一次會問麥克風/音源權限，要按允許，不然蠑螈聽不到。

## 接線

```
電吉他 → 音箱 → 音箱的 LINE OUT 或耳機孔 → 電腦音源輸入孔／錄音介面
```

沒有 line out 也可以直接用電腦麥克風對著音箱收音，但環境要安靜，而且伴奏要戴耳機聽
（不然蠑螈會把喇叭放出來的伴奏聽成你在彈）。

進遊戲先做一次 **自動校準**：安靜兩秒 → 用力刷三下。之後判斷會準很多。
旁邊還有一個調音器，練之前先調音。

## 三種難度

| 難度 | 右手要做的事 | 判定 |
|---|---|---|
| **簡單** | 按好和弦，刷一下就好 | 不限時間，彈對才會換下一個 |
| **中等** | 跟著伴奏，一個和弦刷四下 | 每一下都要對上拍子 |
| **困難** | 照畫面上的箭頭刷指定節奏型 | 時間點 ± 一點點，和弦也要對 |

困難模式有六種節奏型可以選，包括經典的 ↓ ↓↑ ↑↓↑。

## 背景伴奏

中等和困難模式會有鼓、Bass、和弦一起走，整首帶著你前進。
右上角可以調音量，也可以選「只有鼓」或關掉。

想配原曲練的話，選歌頁有「載入自己的伴奏音檔」：選一個你電腦裡的 mp3/m4a，
設定「從第幾秒開始對拍」，再把 BPM 調成那首歌的速度就行。
**音檔只留在你的電腦上，不會上傳到任何地方。**

## 練完會告訴你什麼

- 總分、正確率、最長連段、星星評價
- **哪幾個「換和弦」會卡**：例如 `G → Em` 只有 40%，並告訴你「第 5 弦第 2 格不用放開，當支點轉過去」
- 每個和弦本身的正確率

換和弦那張表才是重點。大部分人不是按不出 F，是「從別的和弦換到 F」來不及。

## 內建歌曲

暖身四和弦循環、五月天《倔強》《笑忘歌》、LUNA SEA《I for you》、
Avril Lavigne《Complicated》《Girlfriend》。

⚠️ **這些和弦是我為了練習排的簡化進行，不是官方樂譜，也沒有對過原曲錄音。**
拿到正式譜（或老師給的譜）之後，請到首頁的「編輯和弦譜」改成正確的，練起來才有意義。
編輯器裡也可以自己加歌，或用 `Gm=355333` 這種寫法定義沒有內建的和弦指法。

## 它是怎麼判斷的

1. 抓聲音輸入，用頻譜變化偵測「你刷了一下」（onset）
2. 刷下去之後等一點點時間讓撥弦雜音過去，取一小段訊號
3. 用 Goertzel 算出每個半音的強度，折成 12 個音級（chroma）
4. 扣掉泛音借來的能量（不然 C 和弦會長出 B，看起來像 Cmaj7）
5. 跟候選和弦的模板比對，加上最低音是不是根音的線索，選最像的

離線用合成吉他訊號測過：判定通過率 99%，**把 A 和弦誤判成 B 和弦的機率 0%**（寧可說「再一次」也不亂放行）。

### 它做不到的事

- **分不出上刷和下刷**。畫面上的 ↓↑ 箭頭是給你看的，實際只判「有沒有在對的時間點刷、和弦對不對」。
- 破音開很大、效果器很濃的音色會比較難判。練和弦建議先用乾淨音色。
- 切到別的分頁遊戲會停下來 —— 瀏覽器會凍結計時器，拍子會整個跑掉，所以乾脆停掉重來。

## 檔案

```
index.html          遊戲本體（單一檔案，所有東西都在裡面）
啟動遊戲.command     雙擊啟動
assets/             蠑螈圖（已經內嵌進 index.html，這裡是原始檔）
build/              原始分段檔 + 建置腳本 + 和弦辨識測試
```

改程式的話：改 `build/` 裡的檔案，然後跑 `python3 build/build.py` 重新產生 `index.html`。
和弦辨識改動之後跑 `node build/test_chord.js` 確認沒有退步。
