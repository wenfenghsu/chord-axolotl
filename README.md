## 怎麼開始

1. Chrome / Edge 開啟遊戲，按「開始」。
2. 電吉他接音箱的 LINE OUT / PHONES，再接電腦錄音介面；選正確的輸入裝置。
3. 按「允許並開始收音」，做一次自動校準。
4. 選歌，播放來源選「官方 YouTube 原曲」，按「播放原曲・自由跟彈」。
5. 戴耳機聽原曲，輸入只收吉他，避免伴奏被誤認為自己彈的。

**目前五首歌尚未附經校對的原曲時間譜。** 舊版的簡化和弦有移調，也未對過原曲換和弦時間，不能拿來替原曲評分。沒有時間譜時是「自由跟彈」：顯示聽到的和弦、累計刷弦數，結算不捏造分數或正確率。

## 加入原曲時間譜後評分

選歌頁展開「設定原曲時間譜與輸入延遲」，貼入這支 MV 對應的正確譜，再按「儲存已校對的時間譜」。格式如下（僅格式示例，不是任一首歌的原譜）：

```text
12.5 C
15.5 G
18.5 REST
21.5 Am
24.5 END
```

每行表示一小節起始的**影片秒數**與和弦，最後的 END 表示評分段落終點。REST 表示不彈。每小節為 4 拍；可用不同的小節長度，但目前不支援小節內變速或其他拍號。和弦請依實際發出的音高填寫，使用移調夾時也需換算。每首歌、每支影片的時間譜分開儲存在此瀏覽器，清除瀏覽器資料會一併清除。

| 難度 | 每小節要做的事 |
|---|---|
| 簡單 | 第一拍刷一下 |
| 中等 | 四拍各刷一下 |
| 困難 | 按指定的八分音符節奏型刷弦 |

YouTube 的影片位置是評分時間來源，緩衝或暫停時停止判定。拖曳影片進度會結算當次，避免把跳過的段落當成漏拍；再按「再來一次」從時間譜前 3 秒重新預備。節奏評分仍受播放器時間精度、收音裝置延遲影響，不能視為錄音室等級的節拍測量。

## 原本的慢練與本機伴奏

播放來源改成「合成伴奏／本機音檔」，即可繼續用內建簡化譜練換和弦。

- 三種難度預設都跟著拍子前進；簡單每小節一下。
- 勾選「簡單慢練：彈對才前進」，可不限時慢練（限合成伴奏，無本機音檔）。
- 可載入自己的 MP3/M4A 等瀏覽器支援音檔，手動設定 BPM 與音檔起點。
- 換歌會清除上一首本機音檔，避免配錯歌。音檔只在記憶體中，不上傳。
- 原曲時間譜與合成伴奏簡化譜分開，不會覆蓋老師幫你改過的舊譜。

## 暫停與結算

「暫停／繼續」保留進度；切分頁自動暫停。「結算」可提早結束，只統計已判定的部分。

有時間譜的練習結束後會列出：總分、正確率、最長連段、各和弦成功率，以及 **G → Em** 這類換和弦組合的成功／失敗次數。分開列出「和弦不符」和「未跟上節拍」；額外刷弦另列，不扣分。換和弦分析採用新小節第一次刷弦，不能只憑少數樣本判定長期弱點。

## 辨識的範圍

收音使用 Web Audio，刷弦起音偵測後，透過 Goertzel 音級分析、泛音抑制與和弦模板比對判斷。演算法只讀吉他輸入，無法從 YouTube 自動分離出原曲吉他或自動生成正確譜。

- 上下刷箭頭是提示；目前不能辨識刷弦方向。
- 建議乾淨音色。破音、環境噪音、和弦按不完整會影響結果。
- 合成訊號測試不能代表真實電吉他辨識率，接上你的音箱／錄音介面後仍需實測調整。

## 本機啟動與原始碼

雙擊 `啟動遊戲.command`；YouTube 仍須連網，合成伴奏可離線使用。

- `build/01_head.html`、`02_body.html`：畫面
- `build/03_data.js`：和弦庫、簡化練習譜
- `build/04_audio.js`：吉他輸入與和弦辨識
- `build/05_game.js`：遊戲與結算
- `build/05_media.js`：官方播放器、原曲時間譜、暫停
- `build/06_ui.js`：介面事件
- `assets/`：原有蠑螈素材

```sh
python3 build/build.py
node --check build/check.js
node build/test_game.js
node build/test_chord.js
```

`test_game.js` 用模擬播放器驗證時間譜、三種難度、暫停／緩衝、輸入延遲、漏拍、換和弦統計與跳轉處理；不代表已測過實際 YouTube 網路播放與實體吉他。
