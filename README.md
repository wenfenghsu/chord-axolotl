# 和弦蠑螈 — Cindy 的 MP3 吉他練習室

[線上版](https://wenfenghsu.github.io/chord-axolotl/)

原曲播放已改用本機 MP3，遊戲沒有 YouTube 播放器或其他外部音樂服務。選歌後顯示當前和弦、下一個和弦、指法圖，以及會跟著音樂亮起的八格刷弦提示。「改和弦譜」已移除，舊瀏覽器儲存的自訂譜不會蓋掉新版資料。

## 本機使用

雙擊資料夾裡的 **`啟動遊戲.command`**。程式從同一個資料夾的 `音樂 MP3/` 讀音樂，伺服器只綁定本機 `127.0.0.1`。

目前有以下兩個音檔，已比對長度及三段波形，與時間譜無偏移：

| 歌曲 | 檔名 | 長度 | 跟彈調性 |
|---|---|---|---|
| 笑忘歌 | `Mayday五月天[笑忘歌] HD MV官方完整版.mp3` | 4:46.093 | G |
| I for You | `LUNA SEA - 「I for You」MV.mp3` | 5:46.755 | C / Am |

《倔強》《Complicated》《Girlfriend》的跟彈時間資料已內建，但目前資料夾尚未有這三首 MP3。之後放進同一資料夾，檔名保留歌名，重新整理即可自動發現（同歌有多個檔案時請手動選取）。也可在選歌頁選取對應版本的 MP3；音檔長度若與譜不同，會停止評分並提示。僅長度相同不能保證內容一致；未比對過的其他版本仍需重新對齊。

線上版按 **「選取這首的 MP3」** 即可播放電腦上的檔案，使用瀏覽器本機 blob URL，**不會上傳 MP3**。原始碼可以放 GitHub，`音樂 MP3/` 與分析暫存已排除，不公開音訊。

## 開始練習

1. Chrome / Edge 開啟遊戲。吉他經音箱 LINE OUT / PHONES 與合適的錄音介面接電腦。
2. 「開始」→「允許並開始收音」→選輸入裝置、校準→選歌。
3. 播放來源保持「MP3 原曲跟彈」，選難度，按「跟 MP3 練習」。
4. 戴耳機聽 MP3，輸入只收吉他，避免把伴奏當成自己的演奏。

| 模式 | 右手目標 |
|---|---|
| 簡單 | 每次換到新和弦時刷一下 |
| 中等 | 每小節四拍各刷一下，途中左手按和弦提示更換 |
| 困難 | 按選定的八分音符節奏型刷弦 |

《笑忘歌》開頭及 166.88–174.50 秒的 MV 對話會顯示休息，不算失誤。曲尾延音後不再要求刷弦。節拍採音檔對應版本的時間資料，而非一直累加固定 BPM。

MP3 `currentTime` 是評分時鐘。「暫停／繼續」、音訊緩衝、切換分頁同步停止評分。拖曳播放器進度會結算當次，避免把跳過音符算成漏拍。「結算」可以提早結束，僅統計已判定的演奏。輸入延遲可用毫秒補償。

## 和弦編配與結算

內建資料是**原調三和弦跟彈編配**。已以錄音節拍、和弦辨識模型、低音頻譜與參考譜交叉檢查，尚未經吉他老師逐拍聽寫驗收，不能宣稱是完全無誤的原曲正式譜；詳見 [校對紀錄](SONG_REVIEW.md)。中等／困難的刷法是練習指定節奏，不是錄音中吉他每一下的完整轉錄。

結算列出總分、正確率、最長連段、各和弦成功率與換和弦組合。換和弦表分開統計「和弦不符」與「未跟上節拍」，採兩個實際要求演奏的和弦比較；休息後不記成換和弦失誤。額外刷弦另列、不扣分。

上下刷箭頭是提示，目前不能辨識方向。建議乾淨音色；真實吉他／錄音介面的延遲與辨識結果仍需现场測試。

「合成伴奏／本機音檔」保留暖身及慢練：每個和弦放一小節，時間不對應完整原曲。簡單慢練可以選彈對才前進。

## 原始碼與驗證

`build/03_originals.js` 放各錄音的和弦／節拍時間；`05_media.js` 控制 MP3、檔案選取與時鐘；`04_audio.js` 判斷吉他；`05_game.js` 計分與結算。頁面由分段檔組成單一 `index.html`。

```sh
python3 build/build.py
node --check build/check.js
node build/test_game.js
node build/test_chord.js
```

排程測試包含五首 × 三種難度的整曲模擬、休息段、暫停、漏拍、換和弦、舊譜隔離、本機音檔選取與移除外部播放器。模擬測試通過不代表採譜全部正確，也不是實體吉他辨識率。
